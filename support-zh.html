漫画阅读器 – 技术支持与使用说明

最后更新：2026-09-09 · 另见 隐私政策 · English Support

一、应用简介（README）

漫画阅读器是一款为 macOS 打造的轻量、流畅的漫画阅读器，让您专注于阅读本身。它在本机本地运行，不联网、不收集任何数据。

  • 支持格式：图片文件夹、zip / cbz / rar / cbr / lzh / cbl 书库，以及 PDF 逐页阅读；也可直接打开单个图片 / PDF 文件。
  • 阅读模式：日式、中式、瀑布三种漫画阅读模式，配合回车 / 点击连贯翻页，翻页后自动对齐画面。
  • 智能续读：同一文件夹中的图片与 PDF 按文件名顺序自动接续阅读（首次使用需授权文件夹，见下文「文件夹授权」）。
  • 灵活的缩放：适应窗口、按宽、按高、原尺寸与指定比例；触控板捏合或阅读区滚轮缩放 / 滚动，方向可在设置中调整。
  • 自动播放与循环：按设定间隔自动翻页，可循环播放。
  • 实用工具：一键打印当前页（⌘P）、灰阶 / 反色 / 裁剪 / USM 锐化滤镜、最近打开、对图片文件夹的查找与批量改名。
  • 多语言：15 种界面语言（简体中文 / English / 日本語 / 繁體中文 / 한국어 / Français / Deutsch / Español / Italiano / Português / Русский / Nederlands / Polski / Türkçe / Tiếng Việt），可跟随系统自动切换。
  • 隐私友好：所有阅读数据仅保存在您的 Mac 上；正式版不发起任何网络连接。详见隐私政策。

系统要求：macOS 13.0 或更高（支持 Apple 芯片与 Intel）。

二、快速开始

1. 安装与启动

在 Mac App Store 中搜索「漫画阅读器」下载安装（正式版不含试用期限制）。启动后界面语言自动跟随系统，也可在环境设置中手动选择。

2. 打开内容

  • 按 ⌘O（文件 → 打开书库/文件夹…）选择图片文件夹、压缩包书库或单个文件；
  • 也可以把文件或文件夹直接拖入窗口。

3. 文件夹授权（重要）

在 App Store 沙盒模式下，应用只能读取您主动打开的内容。分两种情况：

  • 直接打开整个文件夹：打开面板已授予该文件夹访问权，按文件名顺序阅读，无需额外操作；
  • 打开单个图片 / PDF：若该文件所在目录还有后续文件，应用会提示「是否连读同目录文件？」——选择「选择文件夹连读…」并在系统面板中授权该文件夹后，将自动接续阅读同目录后续文件，此授权会被记住，之后无需重复授权；选择「仅当前文件」则只打开这一个文件。

已授予的文件夹可随时在系统设置 → 隐私与安全性 → 文件与文件夹中查看或撤销。

三、详细操作说明

1. 支持的格式与限制

支持：图片文件夹；位图图片（JPEG、PNG、GIF、BMP、TIFF、JPEG 2000、WebP、HEIC 等）；zip / cbz、rar / cbr、lzh / cbl 压缩包；PDF（按页阅读）。

限制：加密 RAR、加密 ZIP 条目暂不支持。

2. 翻页与浏览

  • 键盘：← →、PgUp PgDn、Home End、空格 翻页；回车 的行为可在设置中选择（跟随键位档 / 下一页 / 阅读模式下按模式步进）；翻到首页或末页即停，不循环。
  • 鼠标（画布上）：左键 = 下一页；右键 = 上一页。阅读模式开启时，左键 = 按模式步进（与回车一致）。
  • 滚轮：瀑布模式下 = 图像上下滚动（触控板平滑，滚轮每格约 8% 视口高度，滚到底后再按一次回车 / 点击即翻页）；其余模式下 = 图片全局缩放（每格约 1.12 倍）。滚轮方向可在设置中选择「跟随系统 / 与系统方向相反」。

3. 漫画阅读模式（窗口内「阅读模式」下拉，或 视图 → 阅读模式 子菜单）

  • 日式：先右后左——宽图先看右半幅、再看左半幅，然后翻页；
  • 中式：先左后右——宽图先看左半幅、再看右半幅，然后翻页；
  • 瀑布：每步向下滚动约 95% 视口高度，到底后再次回车 / 点击翻页；
  • 竖版长页（仅高度超出窗口）在日式 / 中式下按屏滚动，节奏与瀑布相同；宽、高都超出时逐角对齐；
  • 整幅完全可见时，回车 / 点击直接翻到下一页；
  • 翻页起点：整幅可见 = 居中；任一侧超出窗口时，瀑布 / 中式 / 无模式从顶部开始，日式从右上角开始（与手动缩放倍率无关）。

4. 缩放

  • 按钮行：适应窗口 / 适应高度 / 适应宽度 / 原寸（快捷键 4 = 适应宽度）；
  • 缩放下拉：按宽 / 按高 / 原尺寸 / 指定比例。前三档为纯档位；「指定比例」= 原尺寸倍数（100 = 1:1，150 = 1.5 倍），仅该档出现百分比输入框，输入后按回车或移开焦点生效；超过 200% 会弹提示（仍会应用，可调回更小数值）；
  • 触控板双指捏合也可缩放。

5. 自动播放

视图 → 播放 / 暂停 开始或暂停自动翻页；停止播放 结束；循环模式 可控制是否循环。自动翻页的间隔在 文件 → 环境设置… 的「翻页间隔（毫秒）」中调整。

6. 滤镜

窗口内「滤镜」下拉可选：无 / 灰阶 / 反色 / 裁剪 5% / USM 锐化。按 F 可在「无」与上一次选择的滤镜之间快速切换。

7. 打印

⌘P（文件 → 打印…）经系统打印面板打印当前页。

8. 查找与批量改名

编辑 → 重命名… 打开「查找与批量改名」：在文件夹书中按文件名主干进行正则查找 / 替换（扩展名保留），可预览匹配数量后「全部替换」；改名仅对文件夹页源生效，压缩包书库不适用。若替换结果为空或含非法字符，相关条目会被跳过。

9. 环境设置（⌘,）

  • 界面语言：跟随系统，或手动选择上述 15 种语言之一（即时切换；跟随系统时若系统语言不在列表中，默认使用英语）；
  • 阅读性能：展开缓存（张）、前进预读（张）、回收上限（MB）；
  • 翻页间隔（毫秒）：自动播放的翻页间隔；
  • 回车键行为：跟随键位档（默认）/ 下一页 / 启动阅读模式时按模式步进；
  • PDF 渲染质量：1.0×（72dpi）/ 1.5×（108dpi）/ 2.0×（144dpi，默认）/ 3.0×（216dpi）——对已打开的文档不生效，调整后需重新打开该 PDF；
  • 滚轮方向：跟随系统方向（默认）/ 与系统方向相反。

10. 其它功能

  • 最近打开：文件 → 打开最近…（最多 5 条）；
  • 关闭书：⌘W 或 文件 → 关闭书；
  • 全屏：视图 → 全屏切换，或使用窗口绿色按钮；
  • 菜单栏图标：视图 → 状态栏图标 可开关菜单栏常驻图标；
  • 帮助：帮助菜单含「版权信息」「开源许可」（应用内可查看所用开源组件及许可全文）；应用菜单含「关于」。

四、常见问题（FAQ）

问：能打开哪些格式？
图片文件夹、图片文件与 PDF 文件、zip / cbz、rar / cbr、lzh / cbl（均需无密码）。

问：如何连续阅读同一个文件夹里的文件？
直接打开文件夹即可按文件名顺序阅读；打开单个文件时首次会提示授权所在文件夹（见上文「文件夹授权」），授权后自动连读且无需重复授权。PDF 会先翻完自身各页，再接续下一个文件。

问：如何缩放？
用底部按钮或缩放下拉，触控板双指捏合，或阅读区滚轮（方向可在设置中调整）。

问：怎么打印？
按 ⌘P 打印当前页。

问：PDF 显示不够清晰？
在环境设置中调高「PDF 渲染质量」（如 3.0×），然后重新打开该 PDF。

问：应用会上传我的数据吗？
不会。应用在本地运行，正式版不发起任何网络连接，不收集、不上传任何数据。详见隐私政策。

问：缩放比例超过 200% 会有问题吗？
会弹出提示但仍会应用缩放，若影响阅读效果调回更小数值即可。
