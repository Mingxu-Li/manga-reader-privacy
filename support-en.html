Manga Reader – Support & User Guide

Last updated: 2026-09-09 · See also Privacy Policy · 中文技术支持

1. About the App (README)

Manga Reader is a light, fast manga reader built for macOS, designed to keep you focused on reading. It runs entirely on your Mac: no network connections, no data collection.

  • Formats: image folders; zip / cbz, rar / cbr, lzh / cbl archives; PDF (page-by-page reading). Single image / PDF files can be opened directly too.
  • Reading modes: Japanese-style, Chinese-style and Waterfall modes for comfortable continuous reading, with auto-alignment after every step.
  • Smart continuation: images and PDFs in the same folder are read consecutively in filename order (folder access is requested once; see “Folder Access” below).
  • Flexible zoom: fit window / width / height, original size or a custom ratio; trackpad pinch and scroll-wheel zoom / scroll, direction configurable.
  • Auto play & loop: page through automatically at a configurable interval, with optional looping.
  • Utilities: print the current page (⌘P), filters (grayscale / invert / crop / USM sharpen), recent items, and find & batch rename for image folders.
  • Languages: 15 interface languages (简体中文 / English / 日本語 / 繁體中文 / 한국어 / Français / Deutsch / Español / Italiano / Português / Русский / Nederlands / Polski / Türkçe / Tiếng Việt), with “Follow System” for automatic switching.
  • Privacy: all reading data stays on your Mac; the release version makes no network connections. See the Privacy Policy.

Requirements: macOS 13.0 or later (Apple silicon and Intel).

2. Getting Started

Install & launch

Download “Manga Reader” from the Mac App Store (the release version has no trial restrictions). The interface follows your system language and can be changed in Preferences.

Opening content

  • Press ⌘O (File → Open Library…), then choose an image folder, an archive, or a single file;
  • or drag a file / folder onto the window.

Folder access (important)

In App Store sandbox mode the app can only read what you explicitly open:

  • Opening a whole folder: access is granted by the Open panel; files are read in filename order with no further steps.
  • Opening a single image / PDF: if more files follow in the same directory, the app asks “Continue reading in the same folder?” — choose “Choose Folder to Continue…” and grant that folder in the system panel to read on automatically. The grant is remembered, so you won’t be asked again. Choose “Open Only This File” to open just that file.

Granted folders can be reviewed or revoked anytime in System Settings → Privacy & Security → Files and Folders.

3. Detailed Usage

Supported formats & limits

Image folders; bitmap images (JPEG, PNG, GIF, BMP, TIFF, JPEG 2000, WebP, HEIC and more); zip / cbz, rar / cbr, lzh / cbl archives; PDF (per page).

Limits: encrypted RAR and encrypted ZIP entries are not supported.

Turning pages & browsing

  • Keyboard: ← →, PgUp PgDn, Home End and Space turn pages. The Return key follows your preference in Settings (follow the key layout / next page / step through the active reading mode). Page turns stop at the first or last page (no looping).
  • Mouse (on the canvas): left click = next page; right click = previous page. With a reading mode active, left click steps through the mode (same as Return).
  • Scroll wheel: in Waterfall mode it scrolls the image vertically (smooth on trackpads; each wheel notch ≈ 8% of viewport height; press Return or click once after scrolling to the bottom to turn the page). In other modes it zooms globally (each notch ≈ 1.12×). Wheel direction can be set to follow the system or reversed.

Reading modes (the “Reading Mode” pop-up, or View → Reading Mode submenu)

  • Japanese: right side first — a wide page shows its right half, then its left half, then turns the page;
  • Chinese: left side first — a wide page shows its left half, then its right half, then turns;
  • Waterfall: each step scrolls down ≈ 95% of the viewport; press Return / click again at the bottom to turn the page;
  • Tall pages (longer than the window) scroll screen-by-screen in Japanese / Chinese mode at Waterfall’s pace; pages wider and taller than the window are read corner by corner;
  • When a page is fully visible, Return / click turns directly to the next page;
  • Step start point: centered when the page fits; otherwise from the top for Waterfall / Chinese / no mode, and from the top-right for Japanese mode (independent of the manual zoom ratio).

Zoom

  • Buttons: Fit to Window / Fit to Height / Fit to Width / Original Size (key 4 = fit width);
  • Zoom pop-up: By Width / By Height / Original Size / Custom Ratio. The first three are simple presets; “Custom Ratio” is a multiplier of original size (100 = 1:1, 150 = 1.5×) and is the only option with a percentage field — press Return or move focus away to apply it. Ratios above 200% show a warning but are still applied;
  • Trackpad pinch zooms as well.

Auto play

View → Play/Pause starts or pauses automatic page turning; Stop Playback ends it; Loop Mode controls whether playback wraps. The page-turn interval is set in File → Preferences… → “Page-turn interval (ms)”.

Filters

The “Filter” pop-up offers None / Grayscale / Invert / Crop 5% / USM Sharpen. Press F to toggle between “None” and your last selected filter.

Printing

⌘P (File → Print…) prints the current page through the system print panel.

Find & batch rename

Edit → Rename… opens “Find & Batch Rename”: regex find / replace on the filename stem of folder books (extensions are kept), with a match count preview before “Replace All”. Renaming applies only to folder page sources — not to archives. Items whose replacement would be empty or contain invalid characters are skipped.

Preferences (⌘,)

  • Interface Language: follow the system, or pick one of the 15 languages listed above (applied immediately; if the system language has no pack, English is used);
  • Performance: expanded cache (pages), forward preload (pages), GC limit (MB);
  • Page-turn interval (ms): the interval used by auto play;
  • Return Key Action: follow the key layout (default) / next page / step per reading mode when active;
  • PDF Render Quality: 1.0× (72 dpi) / 1.5× (108 dpi) / 2.0× (144 dpi, default) / 3.0× (216 dpi) — does not affect already-opened documents; reopen the PDF after changing it;
  • Scroll Wheel Direction: follow the system (default) / opposite to the system.

Other features

  • Open Recent: File → Open Recent… (up to 5 items);
  • Close: ⌘W or File → Close;
  • Full Screen: View → Toggle Full Screen, or the green window button;
  • Menu bar icon: View → Menu Bar Icon shows or hides a menu bar item;
  • Help: the Help menu includes “Copyright Info” and “Open-Source Licenses…” (full license texts of bundled open-source components); “About” lives in the app menu.

4. FAQ

Which formats are supported?
Image folders, individual image / PDF files, and password-free archives: zip / cbz, rar / cbr, lzh / cbl.

How do I read the files of a folder consecutively?
Open the folder itself and files are read in filename order. When you open a single file, macOS asks to authorize that folder the first time (see “Folder access” above); afterwards continuation is automatic and no further prompts appear. A PDF plays through all of its own pages before the next file begins.

How do I zoom?
Use the toolbar buttons or the zoom pop-up, pinch on the trackpad, or use the scroll wheel over the canvas (direction configurable in Preferences).

How do I print?
Press ⌘P to print the current page.

Is the PDF rendering blurry?
Raise “PDF Render Quality” in Preferences (e.g. 3.0×), then reopen the PDF.

Does the app upload my data?
No. It runs locally, makes no network connections in the release version and collects nothing. See the Privacy Policy.

Is zooming above 200% a problem?
A warning appears but the zoom is still applied; lower the ratio if it affects readability.
