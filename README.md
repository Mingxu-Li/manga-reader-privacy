## 关于应用 / About the app

「漫画阅读器」是一款为 macOS 打造的轻量漫画阅读器：支持图片文件夹、zip/cbz、rar/cbr、lzh/cbl 与 PDF 逐页阅读；提供日式/中式/瀑布阅读模式、同目录智能续读、灵活缩放与灰阶/反色等滤镜；应用本地运行，不联网、不收集任何数据。最低系统要求 macOS 13.0（Apple 芯片与 Intel）。

Manga Reader is a light, fast manga reader for macOS: image folders, zip/cbz, rar/cbr, lzh/cbl archives and page-by-page PDF reading; Japanese/Chinese/Waterfall reading modes, smart same-folder continuation, flexible zoom and filters. It runs locally with no network connections and no data collection. Requires macOS 13.0 or later (Apple silicon and Intel).
